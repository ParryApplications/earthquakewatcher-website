Real-time earthquake monitoring and alerts for Android

📱 Download on Google Play

About

EarthQuake Watcher is a comprehensive Android application that provides real-time earthquake data, interactive maps, and customizable alerts to keep you informed about seismic activity worldwide. Stay safe and informed with accurate, up-to-date earthquake information from the USGS (United States Geological Survey).

Features

🗺️ Interactive Maps

Visualize earthquakes on an interactive map with customizable markers and layers.

⚡ Real-time Data

Get the latest earthquake information from USGS in real-time.

🔍 Advanced Filters

Filter earthquakes by magnitude, location, time range, and more.

📊 Detailed Information

View comprehensive details about each earthquake event.

🌙 Dark Mode

Comfortable viewing experience with full dark mode support.

📤 Export Data

Export earthquake data for further analysis and sharing.

Key Capabilities

  • Real-time earthquake data from USGS FDSN Web Services
  • Interactive Google Maps integration with custom markers
  • Customizable magnitude and distance filters
  • Detailed earthquake information including depth, location, and time
  • Dark mode support for comfortable viewing
  • Offline caching for better performance
  • Material Design UI with smooth animations
  • Firebase integration for enhanced features
  • Export earthquake data to CSV/JSON formats
  • Search and filter capabilities
